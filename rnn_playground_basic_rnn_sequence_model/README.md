## A small sequence model using RNNs written from scratch

- Add sentences in the `corpus/file.txt` file (Only lowercase english words, no punctuations)
- From `rnn_playground_basic_rnn_sequence_model` directory, run `python vocab_validator.py` - This adds any new words to the vocabulary (`vocabulary_lib/tokens.txt`)
- From `rnn_playground_basic_rnn_sequence_model` directory, run `python main.py` - This trains an RNN sequence model and generates sample sentences.
