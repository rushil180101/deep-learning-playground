## Vanilla sequence model written from scratch using RNN

- Usage
  - Add sentences to `corpus/file.txt`. It should contain only lowercase letters and no punctuations.
  - Run `python vocab_validator.py` to add any missing words to the vocab manager.
  - Run `python main.py` to train the model and generate samples.
