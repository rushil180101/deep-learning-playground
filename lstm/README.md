## Vanilla sequence model written from scratch using LSTM (long short term memory)

- Usage
  - Add sentences to `corpus/file.txt`. It should contain only lowercase letters and no punctuations.
  - Run `python vocab_validator.py` to add any missing words to the vocab manager.
  - Run `python main.py` to train the model and generate samples.

- Sample sentences generated by this model
  - packages forest the recently git intelligence
  - community enough astronomy earth ordinary failed recipe techniques opening village
  - publicly education difficulties small the man their for the the sources be and
  - containers attracts
  - video every bell basic weekends the and tomatoes create the cultural and storage
